# Cybersecurity Lab Portfolio

## Overview
This project demonstrates hands-on cybersecurity skills using an isolated VirtualBox lab environment.

## Tools Used
- VirtualBox
- Metasploitable 2
- Nmap
- Wireshark

## Lab Environment
- Host-Only Network
- Isolated sandbox setup

## Labs
1. Network Discovery
2. Port Scanning
3. Service Enumeration
4. Packet Analysis
5. Vulnerability Scanning
6. System Hardening
